
# 1. Create a token. It is shown once; the config stores only its SHA-256.
$ mcp-remote-gate token new --id desktop
token: mrg_<the token, masked in this recording>

[[token]]
id = "desktop"
hash = "sha256:2ef3d891a4e7d8bf2f8475161975d27f90cd5d746439a6cba3ffb52ee898ebc4"
scopes = ["tools:list", "tools:call"]
The token above is shown once and stored nowhere. Give it to the client; paste the [[token]] block (it holds only the hash) into gate.toml.

# 5. A send is denied by the gateway; the server never sees it.
$ curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"jsonrpc":"2.0","id":4,"method":"tools/call","params":{"name":"send_message","arguments":{"to":"alice","text":"hello"}}}' http://127.0.0.1:8787/mcp
{"jsonrpc":"2.0","id":4,"error":{"code":-32003,"message":"the tool \"send_message\" is not allowed by the gateway policy"}}
[HTTP 200]
$ test -e sent.log && cat sent.log || echo "sent.log does not exist: the fake server never received a send"
sent.log does not exist: the fake server never received a send
